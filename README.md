# NFL Oddities

A static NFL dashboard: player stats and PPR fantasy points, fourth-down aggressiveness, travel and rest fatigue, referee crew tendencies, and touchdown-luck outliers for the 2026 season.

- `index.html` is the page; `assets/` holds the styles and a small runtime; `data/` holds the stats as JSON.
- The data files are refreshed weekly (Tuesdays) by a scheduled Claude task that commits new JSON to this repo.
- Hosted with GitHub Pages.
